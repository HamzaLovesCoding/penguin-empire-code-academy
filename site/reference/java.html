1 The shape of a program

Main.javaJava
public class Main {                          // file name must match the class name
    public static void main(String[] args) { // where the program starts
        System.out.println("Hello");         // one statement, one semicolon
    }
}

Braces group. Semicolons end statements. The file Main.java must contain class Main, which is the first error most people hit.

2 Variables and types

typesJava
int    ticks    = 20;          // whole numbers
double speed    = 0.7;         // decimals. motor outputs are ALWAYS double
boolean homed   = false;       // true or false
char   grade    = 'A';         // one character, single quotes
String name     = "intake";    // text, double quotes. a class, not a primitive

final double MAX_OUTPUT = 0.8; // final: cannot be reassigned
TypeHoldsWatch out for
intWhole numbers7 / 2 is 3, not 3.5
doubleDecimalsTiny rounding error. Never compare two with ==
booleantrue or falseNot 0 and 1. Java will not convert
StringTextCompare with .equals(), never ==

3 Operators

operatorsJava
+  -  *  /  %          // arithmetic. % is the remainder
=                      // assign
==  !=  <  >  <=  >=   // compare, gives a boolean
&&  ||  !               // and, or, not
+=  -=  *=  /=         // shorthand: x += 1 is x = x + 1
++  --                 // add or subtract one

Math.abs(-3.5)         // 3.5
Math.min(a, b)         // the smaller
Math.max(a, b)         // the larger
Math.max(-0.8, Math.min(0.8, speed))   // the clamp you use all season
Integer division

7 / 2 is 3. Both sides are int, so Java does integer division and throws the remainder away. Make one side a decimal to fix it: 7 / 2.0 gives 3.5.

4 Strings

stringsJava
String s = "Penguin Empire";

s.length()                 // 14
s.charAt(0)                // 'P'
s.substring(0, 7)          // "Penguin"
s.toUpperCase()            // "PENGUIN EMPIRE"
s.contains("Empire")       // true
s.equals("penguin")        // false. USE THIS, not ==
s.equalsIgnoreCase("PENGUIN EMPIRE")   // true
s.trim()                   // strips surrounding whitespace

"arm at " + 9.0            // "arm at 9.0"   string concatenation
System.out.printf("pos %.2f%n", 9.0);  // "pos 9.00" and a newline
== compares identity, .equals() compares content

Two Strings holding identical text can still be two different objects, so == returns false. It sometimes appears to work for short literals, which is what makes it dangerous. Always use .equals().

5 Decisions

if and switchJava
if (position > 9.0) {
    arm.stop();
} else if (position > 4.5) {
    arm.slow();
} else {
    arm.raise();
}

// Ternary: a one-line if/else that produces a value
double speed = homed ? 0.4 : 0.0;

switch (state) {
    case STOWED:  arm.raise(); break;      // break, or it falls through
    case SCORING: arm.stop();  break;
    default:      arm.stop();
}

6 Loops

loopsJava
for (int i = 0; i < 4; i++) { }          // a known number of times

while (!arm.atSetpoint()) { }            // until a condition changes

for (String item : shoppingList) { }     // once per element. "for each"

for (int row = 0; row < 3; row++) {      // nested: rows then columns
    for (int col = 0; col < 3; col++) { }
}

break;      // leave the loop entirely
continue;   // skip to the next pass

A nested loop runs the inner one completely for every single pass of the outer one. Three by three is nine passes.

7 Methods

methodsJava
//  modifier  return-type  name  (parameters)
    public    double       clamp (double value, double limit) {
        return Math.max(-limit, Math.min(limit, value));   // return sends a value back
    }

    public void stop() {          // void returns nothing
        motor.set(0);
    }

// Overloading: same name, different parameter lists. The compiler picks by type.
public void setSpeed(double speed)            { }
public void setSpeed(double speed, boolean safe) { }

Scope. A variable declared inside a method or a block exists only inside it. A field declared in the class exists for the whole object. If the compiler says "cannot find symbol" for something you can clearly see, check which braces it lives inside.

9 Exceptions and null

exceptionsJava
try {
    risky();
} catch (ArrayIndexOutOfBoundsException e) {
    System.out.println("out of range: " + e.getMessage());
} finally {
    // runs either way
}

String name = null;      // "no object here"
name.length();           // NullPointerException

if (name != null && name.length() > 0) { }   // guard first. && stops early
ExceptionMeans
NullPointerExceptionYou called a method on something that is null
ArrayIndexOutOfBoundsExceptionYou asked for an index that does not exist
ArithmeticExceptionInteger division by zero
NumberFormatExceptionYou tried to parse text that is not a number

10 Classes and objects

Intake.javaJava
public class Intake {

    private double speed;              // field: state each object carries
    private final int canId;           // final: set once, in the constructor

    public Intake(int canId) {         // constructor: same name, no return type
        this.canId = canId;            // "this" = the object being built
    }

    public void run(double speed) {    // instance method: acts on THIS object
        this.speed = speed;
    }
}

Intake intake = new Intake(2);    // new builds one. intake is a reference to it
intake.run(0.7);                  // call on the INSTANCE

A class is the blueprint. An object is the thing. One Intake class, and as many Intake objects as you build with new.

static vs instanceJava
public class Constants {
    public static final double kMaxOutput = 0.8;   // belongs to the CLASS
}

Constants.kMaxOutput      // no object needed. like Math.PI
intake.run(0.7);          // instance method: needs an object

11 Encapsulation

ModifierReachable from
publicAnywhere
privateOnly inside the same class
protectedThe same class and its subclasses

Make fields private and expose methods. That is what lets a subsystem promise "nothing else touches this motor" and have the compiler enforce it rather than everyone remembering.

12 Inheritance and polymorphism

inheritanceJava
public class Appliance {
    public void use() { System.out.println("using an appliance"); }
}

public class Oven extends Appliance {          // Oven IS an Appliance
    public Oven() {
        super();                               // call the parent constructor
    }

    @Override
    public void use() {                        // replace the parent's version
        System.out.println("baking");
    }
}

Appliance a = new Oven();   // a variable of the PARENT type
a.use();                    // prints "baking". the OBJECT decides, not the variable

That last line is polymorphism. The variable's type decides what you are allowed to call. The object's actual class decides which version runs. It is why ArmToScoreCommand extends Command lets the scheduler hold a list of plain Command and still run your code.

13 Interfaces and abstract classes

contractsJava
public interface Cookable {          // a contract. no state, no bodies
    void cook();
}

public class Pizza implements Cookable {
    @Override public void cook() { }
}

public abstract class Command {      // partly written. cannot be instantiated
    public void initialize() { }     // a default you may override
    public abstract boolean isFinished();   // no body. subclasses MUST write it
}

14 Enums

enumsJava
public enum ArmState { STOWED, RAISING, SCORING }

ArmState state = ArmState.STOWED;

switch (state) {
    case STOWED:  break;
    case RAISING: break;
    case SCORING: break;
}

A fixed set of named options. The compiler rejects anything outside the list, which a String or an int never would. MotorType.kBrushless is an enum you have used since Unit 4.

15 Lambdas

lambdasJava
() -> intake.runRoller(0.7)      // no arguments, run this line

(a, b) -> a + b                 // two arguments, produce a value

() -> {                         // several statements need braces
    intake.stop();
    arm.stop();
}

intake::stop                    // method reference. shorthand for () -> intake.stop()

A lambda is a small block of code you hand to something else to run later. In robot code that is almost always a button binding: "run this when pressed."

16 Errors you will actually see

The compiler saysIt usually means
cannot find symbolA typo, a missing import, or the variable is out of scope
class X is public, should be declared in a file named X.javaYou renamed the file but not the class, or the reverse
incompatible types: String cannot be converted to intYou are putting the wrong type in. Check what the method returns
missing return statementSome path through the method does not return anything
variable might not have been initializedYou declared it but never gave it a value
unreachable statementCode after a return or break
Read the first error, not the last

One mistake often produces a cascade. Fix the top one and recompile before reading any of the others, because most of them will disappear on their own.

The line number is where the compiler noticed, which is sometimes one line after where you made the mistake. A missing semicolon usually reports on the line below it.
