A to C

TermDefinitionTaught in
Absolute encoderAn encoder that knows its position the moment it powers on, with no homing needed.U5
AdvantageScopeA tool that graphs robot values over time, which is how you find a fault that only lasts a moment.U2
AprilTagA flat printed marker, a little like a QR code, that encodes one number and sits in a known position on the field. One word, capital A and T.U10
AutonomousThe opening seconds of a match where the robot runs itself and nobody can intervene.U11
CAN busThe looped comms wiring connecting the roboRIO to every motor controller. One break kills everything downstream.U1
CAN IDThe address of one device on the CAN bus. Set on the device in a vendor client, and requested by your code.U2
ClampForcing a value into a safe range before it reaches a motor, usually Math.max(-0.8, Math.min(0.8, x)).U6
Closed loopControl where the output is computed from a measurement of what actually happened. The sensor closes the loop.U6
CommandA behaviour with a defined end. It tells subsystems what to do and knows when it is finished.U7
Command groupA command built from other commands, run either in order or together. A group is itself a command.U8
CommandSchedulerThe thing that runs every subsystem's periodic(), polls the buttons and executes every scheduled command, once per 20 ms.U7
ConstantsOne file holding every tunable number, so a change is one line instead of a search across four files.U7
CTRE GeneratorA swerve code generator that requires eight CTRE motors and is the fast path when you have them.U9

D to G

TermDefinitionTaught in
DeadbandA threshold near a joystick's centre that gets ignored, because a stick at rest rarely reads exactly zero.U8
Default commandA command a subsystem runs whenever nothing else is using it.U7
DeploySending your compiled code to the roboRIO over the network.U2
Driver StationThe Windows-only app with Enable and Disable, mode selection, the status lights and the console.U2
EncoderA sensor reporting how far a shaft has turned and how fast it is turning.U5
end(interrupted)The command method that runs once when it stops, whether it finished or was interrupted. Where you stop the motor.U7
ErrorSetpoint minus current position. Signed, because the sign is what tells the motor which way to move.U6
execute()The command method that runs every 20 ms while that command is scheduled. Not the same as periodic().U7
Field-centricDrive control where the stick's direction is a direction on the field, whatever way the robot is facing.U9
Fiducial IDThe number encoded in an AprilTag, telling you which tag you are looking at.U10
GainA number you multiply an error by, such as kP. Gains describe one mechanism and do not transfer to another.U6
GlassA real-time dashboard for watching robot values during a match.U2
GyroThe sensor that measures the robot's heading, without which field-centric control cannot be computed.U9

H to N

TermDefinitionTaught in
HomingMoving a mechanism to a known physical reference and calling that position zero, so later setpoints mean something.U5
initialize()The command method that runs once when the command begins. Not when it ends.U7
InstantCommandA command that runs one action and immediately finishes, which is what lets a one-line call be bound to a button or dropped into a sequence.U8
isFinished()The command method checked every cycle. Return true to end the command.U7
KrakenA CTRE motor with the controller built into it, so CAN runs straight through the motor.U1
LimelightA smart camera used widely across FRC that processes images on the camera and publishes numbers to the robot.U10
Named commandOne of your existing commands, registered under a name so an autonomous routine can call it.U11
NeoA REV motor that plugs into a SparkMax and carries a built-in encoder.U1

O to R

TermDefinitionTaught in
Open loopControl that pushes without measuring the result. set(0.7) and hope.U6
OvershootSailing past the setpoint before coming back. Usually a gain that is too high.U6
Parallel groupCommands run at the same time, ending when all of them end. Only valid for commands using different subsystems.U8
PathA route drawn on a field in PathPlanner, followed approximately by the robot.U11
PathPlannerA desktop app for drawing autonomous routes and generating the code that follows them.U11
PDHPower Distribution Hub. Sends power out to everything and sits on the CAN chain.U1
periodic()The subsystem method that runs every 20 ms always, whether or not any command is scheduled. For observing, not for driving motors.U7
PIDProportional, Integral, Derivative. Closed-loop control that drives an error toward zero.U6
PipelineA saved camera configuration you can switch between from code.U10
RadioThe Wi-Fi link between the driver station and the robot. Imaged at the field for a competition and re-imaged at home afterwards.U1
Relative encoderAn encoder that starts at zero wherever it happens to be at power-on, so it needs homing.U5
RequirementsA command's declaration of which subsystems it needs, so the scheduler can guarantee only one command drives a mechanism at a time.U7
roboRIOThe controller that stores and runs your code. Imaged each season.U1
RobotContainerThe file that creates one instance of each subsystem and wires controller inputs to commands.U8
Robot-centricDrive control where the stick's direction is relative to the robot's own nose.U9

S to Z

TermDefinitionTaught in
Sequential groupCommands run in order, each waiting for the previous one to finish. Ends when the last one ends.U8
SetpointWhere you want the mechanism to be.U6
Settling timeHow long until the mechanism is inside tolerance and stays there.U6
SmartDashboardAn older real-time dashboard, being phased out in favour of Glass.U2
SparkMaxA REV motor controller, which drives a Neo and reads its built-in encoder.U1
Start poseThe position and heading an autonomous routine assumes the robot begins at. A promise you keep with floor tape.U11
Steady-state errorThe small gap left when the proportional term has grown too weak to overcome friction.U6
Sticky faultA fault that occurred at some point, not necessarily right now. Clear it only once you have fixed the cause.U2
SubsystemThe class that owns a mechanism's hardware and is the only place its motors are touched.U7
SwerveA drivetrain where each of the four modules has its own drive motor and its own steering motor. Eight motors.U9
ToleranceHow close counts as arrived. Without it, "at the setpoint" is never quite true.U6
TX / TYLimelight readings: the horizontal and vertical angles to the tag. Both angles, neither a distance.U10
VendordepA JSON file that tells the build system to fetch a vendor's library, such as REVLib.U2
Wait commandA timed pause that is itself a command, so it can sit inside a sequence.U8
WindupWhat happens when the integral term accumulates too much push and carries the mechanism past the target.U6
WPILibThe core FRC library plus its customised build of VS Code.U2
YAGSLYet Another Generic Swerve Library. A cross-brand swerve generator, harder to set up than CTRE's.U9
Two spellings worth getting right

AprilTag is one word with a capital A and a capital T. You will see it written as two words, including in our own source material, and searching for the wrong spelling wastes your time.

The PS5 face button is cross, and the method is .cross(). .x() belongs to the Xbox controller class.
