Does not change

Worth knowing, because it tells you where to spend your re-checking effort.

  • All of Phase 1. Java has not broken source compatibility in this course's lifetime.
  • What P, I and D each do, and the tuning recipe. That is control theory, not an API.
  • The command lifecycle's four method names and their meanings.
  • Init runs at the start of a mode. Periodic runs every 20 ms while in it.
  • Field-centric versus robot-centric control, and why a gyro is required for one of them.
  • That a position means nothing until you know where zero is, whether that is an unhomed encoder, a gyro zeroed facing the wrong way, or a robot placed off its start pose.
  • The reasoning in the console triage table, even when a specific tool's name changes.

4 How to read vendor docs

A short skill nobody teaches explicitly, and it is most of what senior programmers actually do.

  • Check the version first. Before reading a word. Most wasted time starts here.
  • Find the class, then the method list. Vendor sites bury working code in tutorials, and the API reference is usually faster once you know the class name.
  • Read the parameter order out loud. calculate(measurement, setpoint) and calculate(setpoint, measurement) both compile. Only one works.
  • Check the return type. Half of all "cannot find symbol" errors are a method returning something other than what you assumed.
  • Prefer the official docs over a forum post. A forum answer is a snapshot of one season, usually undated, and frequently the top search result.
  • When the docs and the robot disagree, the robot is right. Print the value and look at it.
The habit worth keeping from this course

Every code block in Phase 2 is either verified against a source, or explicitly flagged as needing a check. That is not caution for its own sake. It is what stops a team building three weeks of work on a method that was removed two seasons ago.

When you write code for the team, mark what you verified and what you assumed. The next person cannot tell the difference otherwise.
