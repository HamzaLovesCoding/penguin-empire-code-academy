if / else Decisions

An if statement runs a block of code only when a condition is true. This is how a program stops doing the same thing every time.

1 The if statement

An if takes a boolean inside round brackets. When it is true, the code inside the curly braces runs. When it is false, that code is skipped entirely.

the shape
if (condition) {
    // runs only when condition is true
}
Main.javaJava
double voltage = 11.2;

if (voltage < 11.5) {
    System.out.println("Battery low");
}
output
Battery low

The condition is any expression that produces a boolean, so everything from the previous lesson works here.

2 else

else gives the false path. Exactly one of the two blocks runs, never both and never neither.

Main.javaJava
int ticks = 7;

if (ticks % 2 == 0) {
    System.out.println("even");
} else {
    System.out.println("odd");
}
output
odd

3 else if

else if adds more paths. Java checks each condition in order from the top and runs the first one that is true. Everything after that is skipped, even if it would also have been true.

Main.javaJava
double voltage = 11.2;

if (voltage > 12.0) {
    System.out.println("Battery good");
} else if (voltage > 11.0) {
    System.out.println("Battery low");
} else {
    System.out.println("Swap the battery");
}
output
Battery low

Order matters. If the two conditions were swapped, a voltage of 12.5 would report Battery low, because 12.5 > 11.0 is checked first and is true.

The final else is optional

Without it, all conditions can be false and nothing runs. Include a final else when there must always be an answer.

4 Braces are not optional

Java lets you leave the braces off when the block is a single statement. Do not do this. Without braces, only the very next line belongs to the if.

Main.javaJava
boolean enabled = false;

if (enabled)
    System.out.println("A");
    System.out.println("B");
output
B

The indentation says both lines belong to the if. Java disagrees. Only the A line is controlled by the condition. The B line runs every time. Nothing is reported as an error.

Always write the braces

Indentation means nothing to Java. Braces are the only thing that decides what belongs to the condition. Writing them every time removes this bug permanently.

7 Common mistakes

Watch out for these
  • Leaving off the braces. Only the next line belongs to the condition.
  • Writing if (x = 5) instead of if (x == 5).
  • Putting a semicolon after the condition, as in if (ready);. That ends the statement and the block below runs every time.
  • Ordering else if branches from least specific to most specific. Put the narrowest condition first.
  • Comparing text with == inside a condition. Use .equals(...).
Exercise

Battery Status Report

Report a battery state from its voltage, then decide whether the robot may run.

  1. Print GOOD above 12.0, LOW from 11.0 to 12.0, and REPLACE below 11.0.
  2. Print Match approved only when the state is GOOD and hasBumpers is true.
  3. Otherwise print Match blocked.
  4. Bonus: test all three voltages and both bumper values.
Show one possible solution
solution · Main.java
public class Main {
    public static void main(String[] args) {
        double voltage = 12.4;
        boolean hasBumpers = true;

        boolean good = voltage > 12.0;

        if (good) {
            System.out.println("GOOD");
        } else if (voltage >= 11.0) {
            System.out.println("LOW");
        } else {
            System.out.println("REPLACE");
        }

        if (good && hasBumpers) {
            System.out.println("Match approved");
        } else {
            System.out.println("Match blocked");
        }
    }
}
output
GOOD
Match approved

Storing good in a boolean means the same condition is written once and used twice.
