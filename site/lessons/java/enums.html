Enums & Constants

An enum is a type whose value must be one of a fixed list you write down. It replaces loose numbers and strings with names the compiler checks.

1 The problem with loose values

A robot mode could be stored as a String or an int. Both let you write values that mean nothing.

Main.javaJava
String mode = "telop";     // typo, compiles fine
int mode2 = 47;            // not a real mode, compiles fine

Neither line is reported. Both are wrong. An enum makes both impossible.

2 Declaring an enum

List the allowed values, separated by commas, in capitals by convention.

Main.javaJava
enum RobotMode {
    DISABLED, AUTONOMOUS, TELEOP, TEST
}

RobotMode mode = RobotMode.TELEOP;
System.out.println(mode);
output
TELEOP

Printing an enum gives its name. Writing RobotMode.TELOP is cannot find symbol at compile time, so the typo never reaches the robot.

3 Using one in a switch

Enums and switch fit together well. Inside a case you write the value name alone, without the enum name in front.

Main.javaJava
RobotMode mode = RobotMode.TELEOP;

switch (mode) {
    case AUTONOMOUS -> System.out.println("running auto");
    case TELEOP -> System.out.println("driver in control");
    default -> System.out.println("not moving");
}
output
driver in control

4 values and ordinal

Every enum gets two things for free. values() returns an array of all of them, and ordinal() gives a value's position in the list, counting from 0.

Main.javaJava
for (RobotMode m : RobotMode.values()) {
    System.out.print(m + " ");
}
System.out.println();
System.out.println(RobotMode.TELEOP.ordinal());
output
DISABLED AUTONOMOUS TELEOP TEST
2
Do not rely on ordinal

The number comes from the order you wrote the values in. Insert a new value in the middle and every number after it changes silently. Use the names, not the positions.

5 Giving each value data

An enum is a class. Each value can carry its own data through a constructor.

Main.javaJava
enum Alliance {
    RED("R"), BLUE("B");

    private final String letter;

    Alliance(String letter) {
        this.letter = letter;
    }

    public String getLetter() {
        return letter;
    }
}

System.out.println(Alliance.BLUE.getLetter());
output
B

The value list comes first and ends with a semicolon. The constructor is not public, because you never create enum values yourself. Java creates them once, when the program starts.

6 Enum or final constant

Lesson 3 used final for a single fixed value such as an intake speed. That is still right for one number.

Use an enum when a value must be exactly one out of a known set, and when passing the wrong one should be impossible rather than merely unlikely.

9 Common mistakes

Watch out for these
  • Writing the enum name in front of a value inside a case. Use the bare name.
  • Relying on ordinal(), which shifts whenever the list is reordered.
  • Forgetting the semicolon after the value list when the enum also has fields or methods.
  • Making the enum constructor public. It cannot be.
  • Trying to create a new value with new. The list is fixed at compile time.
Exercise

Scoring Levels

An arm moves to one of three scoring positions.

  1. Declare an enum Level with LOW, MID and HIGH.
  2. Give each one a target angle through a constructor and a getter.
  3. Loop over values() and print each name with its angle.
  4. Write a switch on a chosen level that prints what the arm does.
Show one possible solution
solution · Main.java
enum Level {
    LOW(15), MID(45), HIGH(80);

    private final double angle;

    Level(double angle) { this.angle = angle; }

    public double getAngle() { return angle; }
}

public class Main {
    public static void main(String[] args) {
        for (Level l : Level.values()) {
            System.out.println(l + " is at " + l.getAngle() + " degrees");
        }

        Level target = Level.MID;
        switch (target) {
            case LOW -> System.out.println("Arm barely lifts");
            case MID -> System.out.println("Arm to the middle rung");
            case HIGH -> System.out.println("Arm all the way up");
        }
    }
}
output
LOW is at 15.0 degrees
MID is at 45.0 degrees
HIGH is at 80.0 degrees
Arm to the middle rung

The switch has no default and still compiles, because the three cases cover every value the type allows. That is only possible with an enum.
