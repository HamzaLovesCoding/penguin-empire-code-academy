1 Why this matters

Programming our robot mostly comes down to writing instructions like the ones on this page. When a driver presses a button and the intake spins, somewhere a programmer wrote a line that said “run this motor.” Everything you'll do for Team 2551, from motors and sensors to autonomous, is built out of the basics you're about to learn.

You can learn anywhere

One season, the captain's laptop broke halfway through the year, so he wrote the robot's code on the driver-station laptop for the rest of the season, and the robot still competed. You don't need a powerful computer or a special setup to start. You're going to learn right here, in a browser tab.

2 What a program actually is

A program is a list of instructions that the computer follows in order, from top to bottom. You write the steps, and the computer does exactly what you said, no more and no less.

Computers don't understand English. They understand a very precise, picky language. We'll write in Java, the language FRC robots are programmed in. Java has strict rules about punctuation and spelling. That feels fussy at first, but it's what makes it reliable: the same code does the same thing every time.

Mental model

Think of yourself as writing a recipe for a very literal robot chef. It will do every step perfectly, but only the steps you wrote, exactly as you wrote them.

3 The anatomy of a program

Here is a complete, working Java program. It prints one line of text. Don't worry about memorizing it; we'll walk through every piece right after.

Main.java Java 
public class Main {
    public static void main(String[] args) {
        // This line prints a message to the screen
        System.out.println("Hello, World!");
    }
}

Here's what each line does:

public class Main { … }
Every Java program lives inside a class, which is a named container for your code. Here it's called Main. The { } braces hold everything that belongs to it.
public static void main(...)
The main method is the starting line. When you run the program, the computer looks for main and begins there. For now, treat this exact wording as a magic spell you copy.
// This line prints…
A comment. Anything after // is a note for humans; the computer ignores it. Use comments to explain why you did something.
System.out.println("…")
This is the statement that does the work: it prints whatever is inside the quotes, then moves to a new line. println = “print line.”
"Hello, World!"
A String is text wrapped in double quotes. The quotes mark where the text starts and ends.
; (semicolon)
Ends a statement, like a period ends a sentence. Almost every line of Java instruction ends with one. Forgetting it is the #1 beginner error.

So in plain English, the program says: “Start here. Print the text Hello, World! on its own line. Done.”

6 Common mistakes

Watch out for these
  • Missing semicolon. System.out.println("Hi") with no ; won't compile. The error usually points at the next line, which is confusing, so check the line above it too.
  • Capitalization matters. Java is case-sensitive: System ≠ system, and println ≠ Println. Spelling and case must match exactly.
  • Unmatched quotes or braces. Every " needs a closing ", and every { needs a }. Editors help by highlighting the partner.
  • print vs println. Use println when you want each message on its own line.
Mini-project

The Robot Startup Sequence

When a real robot powers on, it prints status messages to the Driver Station console so the team knows what's happening. You'll recreate that using only what you learned this lesson.

Your task: make the program below print exactly these four lines, in order:

expected output
Booting Penguin Empire 2551...
Intake subsystem: OK
Drivetrain subsystem: OK
Robot ready.
  1. Print the first line using System.out.println(...).
  2. Add three more println statements for the remaining lines.
  3. Run it and compare your output to the target above. It must match exactly.
  4. Bonus: add a comment above the code explaining what the program does.
Stuck? Reveal one possible solution
solution · Main.java
public class Main {
    public static void main(String[] args) {
        // Print the robot's startup status, one line at a time
        System.out.println("Booting Penguin Empire 2551...");
        System.out.println("Intake subsystem: OK");
        System.out.println("Drivetrain subsystem: OK");
        System.out.println("Robot ready.");
    }
}

Notice each message is its own println statement, each ending in a semicolon. The order you write them is the order they print.
