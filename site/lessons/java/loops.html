Loops: while & for

A loop runs the same block of code more than once. Use while when you do not know how many times, and for when you do.

1 The while loop

A while loop checks a condition before each pass. While the condition is true, the block runs again.

Main.javaJava
double rpm = 0;

while (rpm < 4000) {
    rpm += 1200;
    System.out.println("spinning up: " + rpm);
}
output
spinning up: 1200.0
spinning up: 2400.0
spinning up: 3600.0
spinning up: 4800.0

The loop ran four times, and the final value is 4800, not 4000. The condition is only checked between passes, so the last pass overshoots. A loop stops when the condition fails, not at the exact moment a value crosses a limit.

2 Loops that never end

Something inside the loop has to eventually make the condition false. If nothing changes, the loop runs forever.

do not run this
double rpm = 0;
while (rpm < 4000) {
    System.out.println("spinning up");
}
Nothing here changes rpm

The condition is true on every check, so this prints forever. There is no error message. In the sandbox the run will simply time out. Before writing a while, find the line inside it that moves the condition toward false.

3 The for loop

A for loop puts the three parts of a counted loop on one line. Start, condition, and step are separated by semicolons.

the shape
for (start; condition; step) {
    // body
}
Main.javaJava
for (int id = 2; id <= 5; id++) {
    System.out.println("Checking CAN ID " + id);
}
output
Checking CAN ID 2
Checking CAN ID 3
Checking CAN ID 4
Checking CAN ID 5

Read it as three steps. int id = 2 runs once at the start. id <= 5 is checked before every pass. id++ runs after every pass.

Counting from zero

Most loops in Java start at 0 and use < rather than <=, as in for (int i = 0; i < 5; i++). That runs 5 times with i going 0, 1, 2, 3, 4. This matches how positions work in Strings and arrays.

4 Building up a value

Declare the variable outside the loop so it survives between passes, then add to it inside.

Main.javaJava
int total = 0;

for (int i = 1; i <= 5; i++) {
    total += i;
}

System.out.println("total = " + total);
output
total = 15

Declaring total inside the loop would reset it to 0 on every pass and the answer would be 5.

5 break and continue

break leaves the loop completely. continue skips the rest of the current pass and moves to the next one.

Main.javaJava
for (int i = 1; i <= 6; i++) {
    if (i == 4) break;
    if (i % 2 == 0) continue;
    System.out.println("i = " + i);
}
output
i = 1
i = 3

Pass 1 prints. Pass 2 is even so it is skipped. Pass 3 prints. Pass 4 hits break and the loop ends, so 5 and 6 never happen.

8 Common mistakes

Watch out for these
  • Forgetting to change the variable the condition tests, so the loop never ends.
  • Declaring the total inside the loop, which resets it on every pass.
  • Using <= with a zero based count, which gives one extra pass.
  • Putting a semicolon after the for header. The body then runs once, after the loop has finished.
  • Trying to use the loop variable after the loop. It only exists inside.
Exercise

CAN Bus Scan

Print a report over a range of CAN IDs.

  1. Loop over IDs 2 through 9 and print Checking CAN ID n for each.
  2. Skip ID 5 with continue, because that slot is unused.
  3. Count how many IDs you actually checked and print the total afterwards.
  4. Bonus: stop the loop early with break if the ID reaches 8.
Show one possible solution
solution · Main.java
public class Main {
    public static void main(String[] args) {
        int checked = 0;

        for (int id = 2; id <= 9; id++) {
            if (id == 8) break;
            if (id == 5) continue;
            System.out.println("Checking CAN ID " + id);
            checked++;
        }

        System.out.println("checked = " + checked);
    }
}
output
Checking CAN ID 2
Checking CAN ID 3
Checking CAN ID 4
Checking CAN ID 6
Checking CAN ID 7
checked = 5

The break check comes first, so ID 8 ends the loop before anything is printed for it. checked is declared outside the loop so it survives.
