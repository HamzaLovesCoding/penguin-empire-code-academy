1 About this project

This is the capstone for the Java track. It runs across four stages and each one builds directly on the last, so keep your code. At the end you will have a working program that uses almost everything from Units J1 to J5.

Everything runs in one file, because the sandbox compiles a single file. Classes are written as static class inside Main.

2 The Item class

Everything in the kitchen is an item, including Alice. An item has a name, set once when it is created.

Main.javaJava
public class Main {

    static class Item {
        private String name;

        public Item(String name) {
            this.name = name;
        }

        public String getName() {
            return name;
        }
    }

    public static void main(String[] args) {
        Item alice = new Item("Alice");
        System.out.println("Her name is " + alice.getName());
    }
}
output
Her name is Alice

The field is private and the getter is public, which is the encapsulation pattern from lesson 24. Nothing outside the class can change an item's name after it is made.

3 A note on the name Item

The original version of this project called the class Object. Java already has a class called Object that every class inherits from without saying so, and declaring your own hides it. That causes confusing errors as soon as inheritance appears, which is stage 3.

This version uses Item instead. Everything else matches the original.

    }
}
output
Her name is Alice

this.name = name; is needed because the parameter and the field share a name. Without this the line assigns the parameter to itself and the field stays empty.
