2 Comparison operators

Java has six operators that compare two values. Each one produces a boolean.

==
Equal to. Two equals signs, not one.
!=
Not equal to.
>
Greater than.
<
Less than.
>=
Greater than or equal to.
<=
Less than or equal to.
One equals sign stores, two compare

canId = 4 puts 4 into canId. canId == 4 asks whether canId already holds 4. Writing one when you meant the other is the most common mistake in this lesson.

Main.javaJava
int canId = 4;

System.out.println(canId == 4);
System.out.println(canId != 4);
System.out.println(canId > 2);
System.out.println(canId <= 3);
output
true
false
true
false

3 Comparing text

The strings lesson said there was a second comparison symbol that behaves differently on text. This is it.

On numbers, == compares values. On a String, == asks whether the two variables point at the same stored text, not whether the characters match. Sometimes that gives the answer you wanted by accident.

Main.javaJava
String a = "Intake";
String b = "Intake";
System.out.println(a == b);              // true, but only by luck

String typed = "Int";
typed = typed + "ake";                   // same characters, built while running
System.out.println(typed == "Intake");   // false
System.out.println(typed.equals("Intake"));
output
true
false
true

Lines 1 and 2 both hold the text Intake and == reported true. Line 5 also holds the text Intake and == reported false. The characters are identical in both cases.

Always use .equals for text

A test using == on text can pass every time you try it and then fail once the text is built from a file, a dashboard field, or joined pieces. Use == for numbers and booleans. Use .equals(...) for text.

4 AND, OR, NOT

Three operators combine boolean values into a single boolean.

&&
AND. True only when both sides are true.
||
OR. True when at least one side is true.
!
NOT. Flips true to false and false to true.
Main.javaJava
boolean hasGamePiece = true;
boolean armUp = false;

System.out.println(hasGamePiece && armUp);   // both must be true
System.out.println(hasGamePiece || armUp);   // one is enough
System.out.println(!armUp);                  // flips false to true
output
false
true
true
Two symbols, not one

AND is && and OR is ||. Single & and | also exist in Java and do something different. Use the doubled versions.

5 Checking a range

A range check needs two comparisons joined with &&. Java has no way to write -0.8 <= speed <= 0.8 in one piece.

Main.javaJava
double speed = 0.9;
boolean safe = speed >= -0.8 && speed <= 0.8;
System.out.println(safe);
output
false

In lesson 4 you forced a value into that range with Math.min and Math.max. Here you are only asking whether it is already inside.

8 Common mistakes

Watch out for these
  • Writing = where you meant ==.
  • Using == on text. Use .equals(...).
  • Writing 0 < x < 10. Java needs x > 0 && x < 10.
  • Using single & or | instead of the doubled versions.
  • Writing if (ready == true). ready is already a boolean, so if (ready) says the same thing.
Exercise

Shooter Ready Check

A shooter may fire only when three things are true at once. Work out each condition and print the result.

  1. Print whether rpm is at least 4000.
  2. Print whether hasGamePiece is true and the shooter is not jammed.
  3. Print readyToFire, true only when the rpm is high enough, a game piece is loaded, and it is not jammed.
  4. Bonus: print whether subsystem holds the text Shooter.
Show one possible solution
solution · Main.java
public class Main {
    public static void main(String[] args) {
        double rpm = 4200;
        boolean hasGamePiece = true;
        boolean jammed = false;
        String subsystem = "Shooter";

        boolean fastEnough = rpm >= 4000;
        boolean loaded = hasGamePiece && !jammed;
        boolean readyToFire = fastEnough && hasGamePiece && !jammed;

        System.out.println("fastEnough  : " + fastEnough);
        System.out.println("loaded      : " + loaded);
        System.out.println("readyToFire : " + readyToFire);
        System.out.println("is shooter  : " + subsystem.equals("Shooter"));
    }
}
output
fastEnough  : true
loaded      : true
readyToFire : true
is shooter  : true

Storing each condition in its own named boolean makes the final line readable and lets you print the parts separately when one of them is wrong.
