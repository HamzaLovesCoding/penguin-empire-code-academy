2D Arrays (Grids)

A 2D array is an array whose slots are themselves arrays. That gives you rows and columns. The capstone project is built on one.

1 Making a grid

Add a second pair of square brackets. The first number is the number of rows and the second is the number of columns.

Main.javaJava
String[][] kitchen = new String[3][5];   // 3 rows, 5 columns

That creates 15 cells. Every one starts as null, because this is an array of String. A grid of int would start every cell at 0.

2 Reading and writing a cell

Use two indexes. Row first, then column. Both count from 0.

Main.javaJava
kitchen[2][1] = "A";                     // row 2, column 1
System.out.println(kitchen[2][1]);       // A
where that cell is
        col 0   1   2   3   4
row 0     .   .   .   .   .
row 1     .   .   .   .   .
row 2     .   A   .   .   .

Row 2 is the third line down and column 1 is the second position across. Getting the order the wrong way round is the most common mistake with grids.

3 Rows and columns

kitchen.length gives the number of rows. kitchen[0].length gives the number of columns in row 0.

Main.javaJava
System.out.println(kitchen.length);      // 3 rows
System.out.println(kitchen[0].length);   // 5 columns

The reason is that kitchen is an array of rows, and each row is itself an array. Asking a row for its length gives the width of the grid.

Write the loops against length

Using kitchen.length and kitchen[r].length instead of typing 3 and 5 means the grid can be resized by changing one line. The capstone project asks you to grow a grid to 5 by 7, and code written this way needs no other edits.

4 Filling it with nested loops

The nested loop from lesson 11 is exactly the shape needed to visit every cell.

Main.javaJava
String[][] kitchen = new String[3][5];

for (int r = 0; r < kitchen.length; r++) {
    for (int c = 0; c < kitchen[r].length; c++) {
        kitchen[r][c] = ".";
    }
}

The outer counter names the row and the inner counter names the column, which is the same convention as printing a grid.

5 Printing it

Build each row with print, then end the line with println() after the inner loop.

Main.javaJava
kitchen[2][1] = "A";

for (int r = 0; r < kitchen.length; r++) {
    for (int c = 0; c < kitchen[r].length; c++) {
        System.out.print(kitchen[r][c] + " ");
    }
    System.out.println();
}
output
. . . . .
. . . . .
. A . . .

Filling first and printing second matters. Printing a grid of String before filling it prints null in every cell.

8 Common mistakes

Watch out for these
  • Swapping the two indexes. Row comes first.
  • Using grid.length for the column count.
  • Printing a String grid before filling it, which prints null everywhere.
  • Typing the sizes into the loops instead of using length, so resizing the grid breaks the traversal.
  • Writing grid[r, c]. Java needs two separate pairs of brackets.
Exercise

The Kitchen Grid

Build the grid the capstone project uses. In Unit J6 this becomes a real class.

  1. Create a 5 by 7 grid of String and fill every cell with a dot.
  2. Place A at row 3 column 2, F at row 0 column 6, and S at row 4 column 0.
  3. Print the grid with row and column numbers along the edges.
  4. Bonus: write the whole thing so that changing only the two size numbers still works.
Show one possible solution
solution · Main.java
public class Main {
    public static void main(String[] args) {
        String[][] kitchen = new String[5][7];

        for (int r = 0; r < kitchen.length; r++) {
            for (int c = 0; c < kitchen[r].length; c++) {
                kitchen[r][c] = ".";
            }
        }

        kitchen[3][2] = "A";
        kitchen[0][6] = "F";
        kitchen[4][0] = "S";

        System.out.print("  ");
        for (int c = 0; c < kitchen[0].length; c++) {
            System.out.print(c + " ");
        }
        System.out.println();

        for (int r = 0; r < kitchen.length; r++) {
            System.out.print(r + " ");
            for (int c = 0; c < kitchen[r].length; c++) {
                System.out.print(kitchen[r][c] + " ");
            }
            System.out.println();
        }
    }
}
output
  0 1 2 3 4 5 6
0 . . . . . . F
1 . . . . . . .
2 . . . . . . .
3 . . A . . . .
4 S . . . . . .

Nothing in the loops mentions 5 or 7. Change the first line to new String[8][10] and everything still works.
