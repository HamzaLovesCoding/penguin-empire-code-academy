2 A family of items

A fridge, a tomato and Alice are all items, but they behave differently. That is inheritance from lesson 25.

Main.javaJava
static class Appliance extends Item {
    public Appliance(String name) { super(name); }
}

static class Food extends Item {
    private boolean clean = false;

    public Food(String name) { super(name); }

    public boolean isClean() { return clean; }
    public void wash() { clean = true; }
}

Appliance adds nothing yet. It exists so the code can tell a fridge apart from a tomato, which matters in stage 4. Food adds one thing, whether it has been washed.

3 The proximity rule

The project says an object must not be usable from anywhere. Alice has to be next to it. Two items are next to each other when their rows and columns differ by exactly one step in total.

Main.javaJava
public boolean isNextTo(Item a, Item b) {
    int dr = Math.abs(a.getRow() - b.getRow());
    int dc = Math.abs(a.getCol() - b.getCol());
    return dr + dc == 1;
}

public void useObject(Person who, Item what) {
    if (!isNextTo(who, what)) {
        System.out.println(who.getName() + " is too far from the " + what.getName());
        return;
    }
    System.out.println(who.getName() + " uses the " + what.getName());
}

Math.abs from lesson 4 removes the sign, so it does not matter which side Alice is on. Adding the two differences and requiring exactly 1 allows the four cells directly beside her and excludes diagonals.

Allowing diagonals

If you want diagonals to count, the test becomes dr <= 1 && dc <= 1 with the pair not being the same cell. Either rule is defensible. Pick one and be consistent.

4 Alice's inventory

The number of things Alice carries changes while the program runs, so this is an ArrayList and not an array.

Main.javaJava
static class Person extends Item {
    private ArrayList<Item> inventory = new ArrayList<>();

    public Person(String name) { super(name); }

    public ArrayList<Item> getInventory() { return inventory; }

    public void grab(Item item) {
        inventory.add(item);
        System.out.println(getName() + " picked up the " + item.getName());
    }

    public void eat(Food food) {
        if (!food.isClean()) {
            System.out.println(getName() + " will not eat a dirty " + food.getName());
            return;
        }
        inventory.remove(food);
        System.out.println(getName() + " ate the " + food.getName());
    }
}

eat refuses dirty food and returns early, which is the guard pattern from lesson 13. Note the list is declared ArrayList<Item> and not ArrayList<Food>, so Alice can carry anything. That is polymorphism doing useful work.

The import goes at the very top of the file, above public class Main.

public static void main(String[] args) {
    Kitchen kitchen = new Kitchen(5, 7);
    Person alice = new Person("Alice");
    Appliance fridge = new Appliance("Fridge");
    Appliance sink = new Appliance("Sink");

    kitchen.placeObject(alice, 2, 2);
    kitchen.placeObject(fridge, 2, 3);
    kitchen.placeObject(sink, 4, 0);
    kitchen.printKitchen();

    System.out.println();
    kitchen.useObject(alice, fridge);
    kitchen.useObject(alice, sink);

    Food tomato = new Food("tomato");
    alice.grab(tomato);
    alice.eat(tomato);
    tomato.wash();
    alice.eat(tomato);
    System.out.println("inventory size: " + alice.getInventory().size());
}
