Nested Loops & Patterns

A loop inside another loop walks a grid. The outer loop handles rows and the inner loop handles columns. This is the pattern the capstone project runs on.

1 A loop inside a loop

The body of a loop can contain another loop. The inner loop runs all the way through on every single pass of the outer loop.

Main.javaJava
for (int row = 1; row <= 3; row++) {
    for (int col = 1; col <= 4; col++) {
        System.out.print("[" + row + "," + col + "] ");
    }
    System.out.println();
}
output
[1,1] [1,2] [1,3] [1,4]
[2,1] [2,2] [2,3] [2,4]
[3,1] [3,2] [3,3] [3,4]

Follow the numbers. The row stays at 1 while the column runs 1, 2, 3, 4. Only then does the row move to 2 and the column starts over.

2 Counting the passes

Multiply the two counts. An outer loop of 3 containing an inner loop of 4 runs the inner body 3 times 4, which is 12 times.

Nesting multiplies

Two loops of 1000 each means a million passes. That is fine on a laptop and a problem inside a robot loop that has to finish in 20 milliseconds. Know the number before you write it.

3 print against println

Building a grid needs both. System.out.print writes without moving to a new line, so the inner loop can lay out one row. System.out.println() with nothing inside ends that row.

Put the println() after the inner loop and inside the outer loop. That position is what makes the rows break in the right place.

where the line break goes
for (int row = 0; row < 3; row++) {
    for (int col = 0; col < 5; col++) {
        System.out.print(". ");     // stays on the line
    }
    System.out.println();           // ends the row
}
output
. . . . .
. . . . .
. . . . .

Move that println() inside the inner loop and every dot lands on its own line. Move it outside the outer loop and all fifteen dots end up on one line.

4 Drawing a grid

The same shape draws anything laid out in rows and columns. Here the contents depend on the position.

Main.javaJava
int aliceRow = 2;
int aliceCol = 1;

for (int row = 0; row < 3; row++) {
    for (int col = 0; col < 5; col++) {
        if (row == aliceRow && col == aliceCol) {
            System.out.print("A ");
        } else {
            System.out.print(". ");
        }
    }
    System.out.println();
}
output
. . . . .
. . . . .
. A . . .

Rows and columns both count from 0, so row 2 is the third line and column 1 is the second position. This is exactly the grid the capstone project uses in Unit J6.

7 Common mistakes

Watch out for these
  • Putting the line break in the wrong place, which makes the grid one column or one line.
  • Reusing the same variable name for both counters, so the inner loop overwrites the outer one.
  • Using println in the inner loop when you meant print.
  • Forgetting that nesting multiplies the passes.
  • Mixing up which counter is the row. The outer loop is the row in almost all grid code.
Exercise

Print the Kitchen Floor

Unit J6 asks you to draw a kitchen as a grid with objects placed in it. Build the printing half of that now, using only loops.

  1. Print a grid of 5 rows and 7 columns using dots.
  2. Put an A at row 3, column 2 instead of a dot.
  3. Print a row of column numbers above the grid so positions are easy to read.
  4. Bonus: put an F at row 0, column 6 as well, without duplicating the loop.
Show one possible solution
solution · Main.java
public class Main {
    public static void main(String[] args) {
        int rows = 5;
        int cols = 7;
        int aliceRow = 3, aliceCol = 2;
        int fridgeRow = 0, fridgeCol = 6;

        System.out.print("  ");
        for (int col = 0; col < cols; col++) {
            System.out.print(col + " ");
        }
        System.out.println();

        for (int row = 0; row < rows; row++) {
            System.out.print(row + " ");
            for (int col = 0; col < cols; col++) {
                if (row == aliceRow && col == aliceCol) {
                    System.out.print("A ");
                } else if (row == fridgeRow && col == fridgeCol) {
                    System.out.print("F ");
                } else {
                    System.out.print(". ");
                }
            }
            System.out.println();
        }
    }
}
output
  0 1 2 3 4 5 6
0 . . . . . . F
1 . . . . . . .
2 . . . . . . .
3 . . A . . . .
4 . . . . . . .

Using rows and cols as variables rather than typing 5 and 7 means the grid can be resized by editing two lines. Unit J6 asks for exactly that.
