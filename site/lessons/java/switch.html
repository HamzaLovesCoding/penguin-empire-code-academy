switch Statements

A switch compares one value against a list of fixed options and runs the matching branch. It does the same job as a long else if chain when every test is “does this equal that”.

1 The basic form

You give switch a value. Each case lists one option to match. The default branch runs when nothing matched.

Main.javaJava
String mode = "teleop";

switch (mode) {
    case "auto":
        System.out.println("Running autonomous");
        break;
    case "teleop":
        System.out.println("Driver in control");
        break;
    default:
        System.out.println("Disabled");
}
output
Driver in control

A switch works on int, char, String and enums, which you will meet in Unit J5. It only tests equality, so it cannot replace a condition like voltage > 12.0.

Text works here without .equals

A switch on a String compares the characters, not the stored object. This is the one place text comparison behaves the way you would expect without calling .equals(...).

2 break and fall-through

break leaves the switch. Without it, Java keeps running straight into the next case even though that case did not match. This is called fall-through.

missing break
switch (mode) {
    case "auto":
        System.out.println("Running autonomous");
    case "teleop":
        System.out.println("Driver in control");
}

With mode set to auto, that prints both lines. The first case matched, and with no break execution continued into the second one.

A forgotten break is not an error

The compiler accepts it. The program runs. Extra branches simply execute. When a switch does more than you expected, a missing break is the first thing to check.

3 Grouping cases on purpose

Fall-through is useful when several values should do the same thing. Stack the cases with no code between them.

Main.javaJava
int level = 2;

switch (level) {
    case 1:
    case 2:
        System.out.println("low or mid");
        break;
    case 3:
        System.out.println("high");
        break;
}
output
low or mid

Levels 1 and 2 share one block. Level 3 has its own.

4 The arrow form

Newer Java offers an arrow form. Each branch is self contained, so there is no break and no fall-through.

Main.javaJava
switch (mode) {
    case "auto" -> System.out.println("Running autonomous");
    case "teleop" -> System.out.println("Driver in control");
    default -> System.out.println("Disabled");
}
output
Driver in control

Prefer this form in new code. Learn the older form as well, because existing robot code uses it and you will need to read it.

5 When to use which

Use switch when one value is compared against several fixed options. Use if and else if when the conditions are ranges, comparisons, or involve more than one variable.

A switch is not faster in any way that matters. It is easier to read when it fits, and unusable when it does not.

8 Common mistakes

Watch out for these
  • Forgetting break, so later branches run too.
  • Leaving out default, so an unexpected value does nothing at all.
  • Trying to test a range. A switch only compares for equality.
  • Using a variable as a case label. Case values must be fixed at compile time.
  • Mixing the colon form and the arrow form in one switch. Pick one.
Exercise

Robot Mode Router

A robot runs in one of four modes. Print what each one does.

  1. Write a switch on mode handling auto, teleop and test.
  2. Add a default branch that prints Unknown mode.
  3. Give teleop and test the same block, since both are driver controlled.
  4. Bonus: rewrite the whole thing in the arrow form.
Show one possible solution
solution · Main.java
public class Main {
    public static void main(String[] args) {
        String mode = "test";

        switch (mode) {
            case "auto":
                System.out.println("Running the autonomous routine");
                break;
            case "teleop":
            case "test":
                System.out.println("Driver in control");
                break;
            default:
                System.out.println("Unknown mode");
        }
    }
}
output
Driver in control

The arrow form of the same routing:

arrow form
switch (mode) {
    case "auto" -> System.out.println("Running the autonomous routine");
    case "teleop", "test" -> System.out.println("Driver in control");
    default -> System.out.println("Unknown mode");
}
