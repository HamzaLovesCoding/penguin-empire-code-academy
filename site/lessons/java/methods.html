1 What a method is

A method groups statements under a name. Calling the name runs the statements. Nothing inside a method happens until something calls it.

You already use methods written by other people. System.out.println(...) is one. Math.max(...) is another. main itself is a method, and it is the one Java calls to start your program.

2 Declaring one

A method declaration has four parts before the body.

the shape
static void printBanner() {
    System.out.println("=== PENGUIN EMPIRE 2551 ===");
}
static
Covered in section 4. For now, every method you write goes next to main and needs this word.
void
The return type. void means this method hands nothing back. The next lesson covers methods that do.
printBanner
The name. Use camelCase and start with a verb, because a method does something.
()
The parameter list, empty here. The next lesson fills it in.

Methods are written inside the class but outside main. Order does not matter, so a method can sit above or below main and still be callable.

3 Calling it

Write the name followed by parentheses and a semicolon. Java jumps into the method, runs it to the end, then returns to the line after the call.

Main.javaJava
public class Main {

    static void printBanner() {
        System.out.println("=== PENGUIN EMPIRE 2551 ===");
    }

    public static void main(String[] args) {
        printBanner();
        System.out.println("Subsystems online");
        printBanner();
    }
}
output
=== PENGUIN EMPIRE 2551 ===
Subsystems online
=== PENGUIN EMPIRE 2551 ===

The banner text is written once and printed twice.

Declaring is not calling

A method that is never called never runs. If you write a method and see no output, check that main actually calls it.

4 The word static

static means the method belongs to the class itself rather than to an object made from it. You have already seen the effect. Math.max(3, 9) is called on the name Math, not on a Math you created.

Because main is static, every method it calls directly must be static too. Unit J5 explains what the alternative is and when to use it.

For now, write static

Leaving it out gives the error non-static method cannot be referenced from a static context. That message means exactly what this section describes.

5 Why bother

Three reasons, in order of how much they matter.

  1. One place to change it. The same reason a final value beat ten copies of 0.65 in lesson 3.
  2. A name explains the code. clamp(speed) says what is happening. Math.min(0.8, Math.max(-0.8, speed)) makes the reader work it out.
  3. Smaller pieces are easier to fix. When a method produces the wrong answer, the bug is inside those few lines.

In Phase 2 every subsystem is a set of methods. runRoller(0.7) and stop() are methods you will write on a real robot.

8 Common mistakes

Watch out for these
  • Writing a method and never calling it.
  • Leaving off static, which gives non-static method cannot be referenced from a static context.
  • Declaring a method inside main. Methods go beside main, not inside it.
  • Forgetting the parentheses when calling, which makes Java look for a variable instead.
  • Naming a method after a noun. Use a verb, since a method performs an action.
Exercise

Startup Sequence

Split a startup report into named methods.

  1. Write printBanner to print the team header.
  2. Write printSubsystems to print three subsystem lines.
  3. Write printReady to print a final line.
  4. Call all three from main, in order. main should be three lines long.
Show one possible solution
solution · Main.java
public class Main {

    static void printBanner() {
        System.out.println("=== PENGUIN EMPIRE 2551 ===");
    }

    static void printSubsystems() {
        System.out.println("Intake     OK");
        System.out.println("Shooter    OK");
        System.out.println("Drivetrain OK");
    }

    static void printReady() {
        System.out.println("Robot ready.");
    }

    public static void main(String[] args) {
        printBanner();
        printSubsystems();
        printReady();
    }
}
output
=== PENGUIN EMPIRE 2551 ===
Intake     OK
Shooter    OK
Drivetrain OK
Robot ready.

A three line main reads as a summary of what the program does. The detail sits inside the methods.
