Arrays (1D)

1 Making an array

There are two ways. Use the first when you already know the values, and the second when you do not.

Main.javaJava
int[] canIds = {2, 3, 4, 5};        // known values
double[] speeds = new double[3];    // three empty slots

The square brackets after the type mean “an array of these”. An array has a fixed size, decided when it is created. You cannot add a fifth slot to canIds later. The next lesson but one covers a structure that can grow.

Empty slots are not empty

new double[3] fills every slot with 0.0. An int array fills with 0, a boolean array with false, and a String array with null. That last one matters, and the exceptions lesson comes back to it.

2 Reading and writing a slot

Each slot has a position, called an index. Counting starts at 0, exactly as it did for characters in a String.

the ruler
   +---+---+---+---+
   | 2 | 3 | 4 | 5 |
   +---+---+---+---+
     0   1   2   3
Main.javaJava
System.out.println(canIds[0]);   // 2
canIds[1] = 9;                   // change the second slot

3 length

canIds.length gives the number of slots. Note there are no parentheses. A String uses length() with parentheses, and an array uses length without them. This inconsistency is real and it catches everybody once.

Main.javaJava
System.out.println(canIds.length);                 // 4
System.out.println(canIds[canIds.length - 1]);     // 5, the last slot

length - 1 is the last index. That is the same pattern as the last character of a String.

4 Looping over an array

A counted loop from 0 up to length visits every slot exactly once.

Main.javaJava
int[] canIds = {2, 3, 4, 5};

for (int i = 0; i < canIds.length; i++) {
    System.out.println("index " + i + " = " + canIds[i]);
}
output
index 0 = 2
index 1 = 3
index 2 = 4
index 3 = 5

Using i < length rather than i <= length is what keeps the loop inside the array. This is why loops are written with < so often.

5 The for-each loop

When you need the values but not the positions, this shorter form reads better.

Main.javaJava
for (int id : canIds) {
    System.out.println("id " + id);
}

Read the colon as “in”. For each int called id in canIds. There is no index variable, so use the counted form when you need to know the position or want to change slots.

6 Going out of bounds

Asking for an index that does not exist stops the program.

console
Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException:
        Index 3 out of bounds for length 3

The message names the index you asked for and the length you had. An array of length 3 has indexes 0, 1 and 2. This is the same shape of message as the String crash in lesson 5.

9 Common mistakes

Watch out for these
  • Writing length() on an array. Arrays use length with no parentheses.
  • Looping with i <= length, which runs one slot past the end.
  • Expecting an array to grow. The size is fixed when it is created.
  • Assuming index 1 is the first slot.
  • Trying to change values with a for-each loop. Use the counted form for that.
Exercise

Motor Speed Report

Work over an array of motor speeds.

  1. Print every speed with its index.
  2. Find and print the largest speed using a loop.
  3. Count how many are above 0.8 and print the count.
  4. Bonus: print the average.
Show one possible solution
solution · Main.java
public class Main {
    public static void main(String[] args) {
        double[] speeds = {0.4, 0.95, 0.7, 0.85, 0.2};

        for (int i = 0; i < speeds.length; i++) {
            System.out.println("motor " + i + " at " + speeds[i]);
        }

        double largest = speeds[0];
        int tooFast = 0;
        double total = 0;

        for (int i = 0; i < speeds.length; i++) {
            if (speeds[i] > largest) {
                largest = speeds[i];
            }
            if (speeds[i] > 0.8) {
                tooFast++;
            }
            total += speeds[i];
        }

        System.out.println("largest  = " + largest);
        System.out.println("over 0.8 = " + tooFast);
        System.out.println("average  = " + (total / speeds.length));
    }
}
output
motor 0 at 0.4
motor 1 at 0.95
motor 2 at 0.7
motor 3 at 0.85
motor 4 at 0.2
largest  = 0.95
over 0.8 = 2
average  = 0.62

largest starts at the first value rather than 0, so the comparison works even when every speed is negative.
