ArrayList & Collections

An array has a fixed size. An ArrayList grows and shrinks while the program runs, which is what you need when you do not know how many items there will be.

1 The import line

ArrayList is not built into the language the way int and arrays are. It lives in the Java library, so you must import it at the very top of the file, above the class.

Main.javaJava
import java.util.ArrayList;

public class Main {
    // ...
}

Without it you get cannot find symbol on the word ArrayList, which is the same message you met for typos in lesson 6.

2 Creating one

The type in angle brackets says what the list holds. Every item must be that type.

Main.javaJava
ArrayList<String> inventory = new ArrayList<>();

The angle brackets on the right can stay empty, because Java reads the type from the left side. A new list starts with nothing in it and a size of 0.

It cannot hold int directly

ArrayList<int> does not compile. Use ArrayList<Integer> for whole numbers and ArrayList<Double> for decimals. Java converts between int and Integer automatically, so you can still write list.add(5).

3 The methods you need

.add(item)
Puts an item on the end. The list grows by one.
.get(index)
Reads the item at a position. Counts from 0, like an array.
.size()
How many items. Note the parentheses. An array uses length with none.
.remove(item)
Removes it and closes the gap. Everything after it shifts down one position.
.contains(item)
Gives true or false.
.isEmpty()
true when the size is 0.
Main.javaJava
ArrayList<String> inventory = new ArrayList<>();
inventory.add("tomato");
inventory.add("cucumber");
inventory.add("grapes");

System.out.println(inventory.size());
System.out.println(inventory.get(1));
System.out.println(inventory.contains("tomato"));

inventory.remove("cucumber");
System.out.println(inventory);
output
3
cucumber
true
[tomato, grapes]

Printing the list itself gives a readable form with square brackets and commas. An array printed the same way gives an unhelpful code instead, so this is one place a list is easier.

Removing shifts everything after it

After removing cucumber, grapes moved from index 2 to index 1. Any index you stored before the removal is now pointing at the wrong item. This is why removing inside a loop that counts upward skips items.

4 Looping over it

Both loop forms work. Use size() rather than length.

Main.javaJava
for (int i = 0; i < inventory.size(); i++) {
    System.out.println(inventory.get(i));
}

for (String item : inventory) {
    System.out.println(item);
}

5 Array or ArrayList

Use an array when the number of items is fixed and known, such as four swerve modules or a grid of cells.

Use an ArrayList when items are added and removed while the program runs, such as an inventory of collected items.

The capstone project uses both. The kitchen floor is a 2D array because its size is fixed. Alice's inventory is an ArrayList because she picks things up and puts them down.

8 Common mistakes

Watch out for these
  • Forgetting the import, which gives cannot find symbol.
  • Writing .length on a list. A list uses .size().
  • Writing ArrayList<int>. Use Integer.
  • Using square brackets to read an item. A list uses .get(i).
  • Removing items inside a counting loop, which skips the item after each removal.
Exercise

Alice's Inventory

Build the inventory the capstone project needs.

  1. Create a list of String and add three items.
  2. Print the size and the whole list.
  3. Check whether the list contains tomato and print the result.
  4. Remove one item, then print the list and size again.
  5. Bonus: loop over the list and print each item with its position.
Show one possible solution
solution · Main.java
import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        ArrayList<String> inventory = new ArrayList<>();
        inventory.add("tomato");
        inventory.add("cucumber");
        inventory.add("grapes");

        System.out.println("size:     " + inventory.size());
        System.out.println("contents: " + inventory);
        System.out.println("tomato?   " + inventory.contains("tomato"));

        inventory.remove("cucumber");
        System.out.println("after remove: " + inventory);
        System.out.println("size:     " + inventory.size());

        for (int i = 0; i < inventory.size(); i++) {
            System.out.println("  " + i + ": " + inventory.get(i));
        }
    }
}
output
size:     3
contents: [tomato, cucumber, grapes]
tomato?   true
after remove: [tomato, grapes]
size:     2
  0: tomato
  1: grapes

Notice grapes is at index 1 after the removal. It was at index 2 before.
